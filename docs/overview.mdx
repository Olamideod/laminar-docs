Laminar is an open-source observability platform purpose-built for AI agents. It gives you tracing, evaluations, dataset management, and production monitoring in one platform. You can be up and running with one line of code.

## What Laminar does

When you initialize Laminar in your application, it automatically instruments your LLM calls. Every request to OpenAI, Anthropic, Gemini, or any supported provider is captured as a trace. You see the full execution flow in the Laminar dashboard: inputs, outputs, latency, token usage, and cost.

Beyond tracing, Laminar gives you a structured way to evaluate your application, annotate outputs, build datasets, and monitor behavior in production.

## One-line setup

<Tabs>
  <Tab title="Python">
    ```bash
    pip install lmnr
    ```

    ```python
    from lmnr import Laminar
    Laminar.initialize(project_api_key="your-api-key")
    # Your OpenAI, Anthropic, and other LLM calls are now traced automatically.
    ```
  </Tab>
  <Tab title="TypeScript">
    ```bash
    npm install @lmnr-ai/lmnr
    ```

    ```typescript
    import { Laminar } from '@lmnr-ai/lmnr';
    import { OpenAI } from 'openai';
    
    Laminar.initialize({
      projectApiKey: process.env.LMNR_PROJECT_API_KEY,
      instrumentModules: { openAI: OpenAI },
    });
    // Your OpenAI calls are now traced automatically.
    ```
  </Tab>
</Tabs>
